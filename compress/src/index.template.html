Saving

Every Save button writes straight to your device — nothing is uploaded. In a sandboxed preview frame or in-app browser the browser blocks downloads: use Open in its own tab at the top, then Save works normally.

Lossless first

Every file starts with a bit-exact pass: PNG predictors are re-optimised, JPEG metadata stripped, PDF objects re-serialised and dead ones dropped, Office XML re-packed. If that already hits your target, nothing else runs — the result is byte-for-byte faithful.

Target, not blind

10 / 25 / 50 / 75 / 90 % and Extreme are sizes to reach. The engine climbs a ladder — quality 97 → 18, long edge 3200 → 640 px — and stops at the first rung that lands under your target without breaking the fidelity floor. Gentlest possible setting, every time.

Audited quality

Anything lossy is measured against the original (PSNR and global SSIM) and the number is printed next to the result. No silent damage: if a pass cannot help, the file is returned untouched.
